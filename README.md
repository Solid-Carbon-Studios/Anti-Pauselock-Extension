# Anti-Pauselock-Extension
Tired of YTTV and similar pausing when browsing? Use this!

Description: A small unnoticeable hitch to allow you to watch a disney movie or cartoons and view the tvguide on apps like YTTV (more support coming eventually if needed be sure to leave a site you seek to use this on and it will be considered for update.)

Step by Step:

Step 1: Open your browser of choice and enter the Extensions tab
Step 2: Ensure DEVELOPER MODE IS ACTIVE.

-Leave tab open and continue-

Step 3: Organize the .json, .js, and .png into a folder named "Anti-pauseblock"
Step 4: Click onto the Extensions tab in your browser (reopen it if you've ignored the middling step)
Step 5: Click "Load Unpacked"
Step 6: Select the FOLDER "Anti-pauseblock"
Step 7: If you are currently watching something be sure to refresh the tab so the extension can take effect.

The code is visible so there should be no misconception of intent but if you experience an anomaly in your experience be sure to leave a note somewhere in my online presence.
Good luck and happy watchin ^u^
